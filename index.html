تشغيل سريع وبسيط

انطلق بموقعك خلال أقل من 5 دقائق

اختر بين معالج التثبيت المرئي السهل عبر المتصفح، أو التثبيت البرمجي عبر سطر الأوامر.

1

1. تنزيل واستخراج الملفات

قم بتنزيل أحدث حزمة إصدار v4.5.6 من GitHub واستخرج محتوياتها داخل المجلد الرئيسي لسيرفر الويب الخاص بك.

2

2. فتح معالج التثبيت في المتصفح

افتح الرابط في متصفحك (مثلاً: https://yourdomain.com/install) لبدء المعالج التفاعلي خطوة بخطوة.

3

3. ربط قاعدة البيانات والانطلاق

أدخل بيانات الاتصال بقاعدة البيانات، وأنشئ حساب المدير، ثم اضغط على زر التثبيت. سيتولى السكربت إعداد كل شيء تلقائياً!

1

1. استنساخ المستودع وتثبيت الحزم

git clone https://github.com/mrghozzi/myads.git && cd myads && composer install
2

2. ضبط ملف الإعدادات وتوليد المفتاح

cp .env.example .env && php artisan key:generate
3

3. تشغيل التهجيرات وبدء السيرفر

php artisan migrate --seed && php artisan serve

نعم بكل تأكيد. الكود المصدري الرسمي لتطبيق الجوال Flutter متاح في مستودع mrghozzi/myads_app مع كامل الشروحات وخطوات البناء والإنتاج.
